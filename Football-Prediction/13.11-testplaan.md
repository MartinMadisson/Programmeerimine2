# 13.11 tund – failid ja valideerimine (Football Prediction)

Testimiseks kasuta `KooliProjekt.WebAPI/KooliProjekt.WebAPI.http` faili (Visual Studio) või `/swagger`.

## Failid (Team logo)
Failid salvestatakse: `{FilesRoot}/teams/{teamId}/{guid}.{laiend}`.
FilesRoot on `appsettings.json` failis (vaikimisi `c:\temp\uploads\`).

| Käsk/päring | Endpoint | Kontrolli |
|---|---|---|
| AddFileCommand | POST /api/Teams/addfile?id=1 (form-data, `file`) | fail tekib kausta teams/1, vastuses fileName |
| ListFilesQuery | GET /api/Teams/listfiles?id=1 | tagastab lisatud failide nimed |
| GetFileCommand | GET /api/Teams/getfile?id=1&fileName=... | tagastab pildi |
| DeleteFileCommand | DELETE /api/Teams/deletefile | fail kaob kettalt, uuesti kustutades "File not found." |
| DeleteTeamCommand | DELETE /api/Teams/delete | kustub ka tiimi failid |

Valideerimine: tiim peab olema olemas, Id >= 1, failinimi ilma kaustateedeta, laiend jpg/jpeg/png/gif/webp,
fail ei tohi olla tühi ega > 2 MB. Proovi ka .txt faili ja > 2 MB pilti.

## Validaatorid (kõik käsud ja päringud)
- Teams / Tournaments / Players Save: Name kohustuslik, <= 100, unikaalne
- Matches Save: Turniir ja tiimid olemas, tiimid erinevad, skoor 0..30, RoundId 1..4, kuupäev kohustuslik, sama paar samas voorus/turniiris ei kordu
- Predictions Save: Match ja User olemas, skoor 0..20 ("reaalne"), Points 0..10, üks ennustus kasutaja kohta mängu kohta
- Scoreboards Save: User ja Tournament olemas, Score >= 0, üks kirje kasutaja kohta turniiri kohta
- Users Save: username kohustuslik <= 50 (andmebaasi piirang), parool <= 100; kasutajanimi unikaalne (suurtähtedest sõltumatult), parool ei tohi olla sama mis kasutajanimi ega mõne teise kasutaja nimi (alates 20.11 salvestatakse paroolid räsina, seega parooli unikaalsust enam ei kontrollita)
- Kõik Get / Delete: Id >= 1
- Kõik List: Page >= 1, PageSize 1..100
