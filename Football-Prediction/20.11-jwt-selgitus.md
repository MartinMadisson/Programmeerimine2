# 20.11 tund – JWT autentimine (Football Prediction)

## Mis on JWT lühidalt
1. Kasutaja saadab kasutajanime ja parooli: `POST /api/Authentication/authenticate`.
2. Server kontrollib parooli (`PasswordHelper.Verify`) ja annab vastuseks **tokeni** (pikk tekst kolme punktiga eraldatud osast).
3. Kasutaja saadab selle tokeni igas järgmises päringus päises: `Authorization: Bearer <token>`.
4. Server kontrollib tokeni allkirja (`Jwt:Key`, `Issuer`, `Audience`, aegumine). Kui ok, siis teab, kes päringu tegi.
5. `[Authorize]` ApiControllerBase peal tähendab: ilma kehtiva tokenita vastab server `401 Unauthorized`.
   `[AllowAnonymous]` authenticate actionil teeb ühe erandi, muidu ei saaks keegi sisse logida.

## Kuidas kontrollida
**13. Sisselogimine Swaggeris**
1. F5, ava `/swagger`.
2. `POST /api/Authentication/authenticate` -> Try it out -> `{"userName":"admin","password":"Admin123!"}` -> Execute.
3. Vastuses `value` on token. Sama `kasutaja` kontoga.
4. Vale parooliga peab tulema `400` ja "Invalid username or password."

**14. Admin tokenis on roll**
1. Kopeeri token (ilma jutumärkideta) lehele https://jwt.io ja vaata Payload osa.
2. Admini tokenis peab olema `"role": "Admin"`. Tavakasutaja tokenis rolli ei ole.
   (Token ei ole salajane, see on lihtsalt Base64. Allkiri tagab, et seda ei saa muuta.)

**15. Postman**
1. `POST http://localhost:5189/api/Authentication/authenticate`, Body -> raw -> JSON.
2. Kopeeri token. Teises päringus: Authorization vahekaart -> Type: Bearer Token -> kleebi token.
3. Proovi `GET /api/Teams/list/1/10`, `POST /api/Teams/save`, `DELETE /api/Teams/delete` jne **mõlema kasutajaga**: kõik peavad töötama (`200`).
4. Proovi sama ilma tokenita: peab andma `401`.

`KooliProjekt.WebAPI.http` failis on samad testid valmis (A1-A9).

## Ülevaade: mida me päriselt õppisime
- **Autentimine** = kes sa oled (login, token). **Autoriseerimine** = mida tohid (`[Authorize]`, rollid).
- **Paroole ei hoita tavatekstina**: `PasswordHelper.Hash` teeb soolatud PBKDF2 räsi, `Verify` kontrollib. Sama parool annab iga kord erineva räsi, seepärast ei saa enam kontrollida "parool peab olema unikaalne".
- **Claim** on tokenis olev fakt kasutaja kohta (id, nimi, roll). `IUserProvider` loeb need claimid `HttpContext`ist.
- **Middleware järjekord**: `UseAuthentication()` enne `UseAuthorization()`.
- **Migratsioon**: andmebaasi struktuuri muutus (uus veerg `IsAdmin`) tehakse koodis ja rakendatakse andmebaasile.
